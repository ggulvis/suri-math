# 수리수리 🦉

듣고, 세고, 생각하는 7세(만 5~6세) 수학 모험 PWA.

## 차별화 포인트 (vs 라임타운류 게임형 수학앱)

1. **모든 문제를 읽어준다** — Web Speech API 한국어 TTS + 이모지 시각화. 글을 못 읽어도 문장제를 풀 수 있다.
2. **보기가 곧 진단이다** — 선택지를 오개념별 함정으로 구성 (`5+3`에서 7/9 = 하나씩 세기 실수, 2 = 연산 혼동). 무엇을 골랐는지가 진단 데이터가 된다.
3. **오답 → 즉시 스캐폴드** — 그림을 하나씩 눌러 세는 재도전 기회. 두 번 틀리면 세기 애니메이션과 함께 정답 공개.
4. **진단 → 처방 출제** — 취약 오개념을 겨냥한 문제를 다음 출제에 주입 (remediation 큐).
5. **부모 리포트 = 진도율이 아니라 행동 제안** — "정답에서 1 차이 실수가 잦아요 → 오늘 저녁 과자 6개로 같이 세어 보세요."
6. **LLM은 오프라인 배치에서만** — 문항 템플릿을 로컬 ollama로 생성·결정론 검증 후 번들. 서버비 0, 아이에게 실시간 LLM 출력 노출 0.

## 구조

- `index.html` — 앱 전체 (엔진 + UI + 부모 리포트). 빌드 없음.
- `problems.json` — 이야기 문제 템플릿 뱅크 (생성물).
- `scripts/gen-problems.mjs` — ollama 배치 생성기: `node scripts/gen-problems.mjs 10`
- `sw.js` — 오프라인 캐시 (network-first). 배포 시 `VERSION` 올릴 것.

## 개발

로컬: `python3 -m http.server 8123 --directory .` → http://localhost:8123
(TTS·PWA 설치는 https 필요 — GitHub Pages에서 확인)

## 데이터

학습 기록은 전부 기기 localStorage (`suri.v1`). 계정·서버·수집 없음.
